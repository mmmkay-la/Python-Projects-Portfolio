# Python Development Projects

List of Projects, created mainly using Python, to enhance and showcase skills in development.

### [Desktop File Organizer](file-organizer-proj)
A Python script that organizes files from a chosen source folder by sorting them into category-based folders or moving them into common user folders such as Documents, Pictures, and Music.

### [Senate Score Card](web-scraper)
A Python script that builds a DuckDB data warehouse by retrieving Philippine Senate data through API calls and storing it in structured tables. It also provides an option to generate a report showing bills authored by current senators to help track legislative activity and progress.
